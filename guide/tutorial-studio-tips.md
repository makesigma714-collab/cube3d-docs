# Studio Tips

<figure><img style="max-width:100%;height:auto" src="/scripting-studio.jpg" alt="Empty Starter Place" loading="lazy"/><figcaption>Empty Starter Place</figcaption></figure><ul><li>Right-click in the Explorer to add parts/scripts/teams/tools.</li><li>Drag a script onto a part or model. It will now be inside it, and the script’s parent (<code>script.Parent</code>) will be that part or model.</li><li>Select parts and click Group to put them in a model. Click Weld to make them move together.</li><li>The <b>Toolbox</b> has ready-made models like doors, teleporters, NPCs, a sword and an RPG, plus scripts like Sprint System and Auto Weld.</li><li>The Part button can add blocks, spheres, cylinders, wedges and more.</li><li>Choose <b>Creator Marketplace</b> in the Toolbox to drop in approved meshes, decals and faces from any creator. You can also type a Mesh ID or Decal ID into a part&#x27;s Properties.</li><li>The View buttons open and close the Explorer, Properties, Output and Toolbox.</li><li>Kill bricks and seats don’t need any code. Simply change the Type in Properties.</li><li>Use WASD to fly. Hold right-click to look around.</li></ul>
