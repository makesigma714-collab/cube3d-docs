# Introduction

Cube3D games are scripted in Lua. Scripts are written in Studio's **Scripts** tab, saved with the
world and published with each game version. Press **Play** in Studio to run them straight away, with
no publishing. A game server only ever runs the scripts of the version that was published.



Start with [your first script](/guide/starting-out), then read about [server and client scripts](/guide/server-scripts-and-client-scripts).
