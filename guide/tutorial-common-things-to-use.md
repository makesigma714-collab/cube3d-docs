# Common Things to Use

<div><div><h3>Players</h3><ul><li><code>Players.PlayerAdded</code> - Someone has joined the game.</li><li><code>player:SendMessage(text)</code> - Sends a message to their chat.</li><li><code>player.Chatted</code> - Fires with each chat message they send. Good for chat commands.</li><li><code>player:Kick(reason)</code> - Removes them from the server and shows them the reason.</li><li><code>player:Respawn()</code> - Respawns the player.</li><li><code>player:SetStat(name, value)</code> - Changes their leaderboard stat.</li><li><code>player.Character.WalkSpeed</code> - Changes their walk speed (0-64). Can only be done on the server.</li><li><code>player.Character.Humanoid</code> - Their Humanoid, with Health, MaxHealth, WalkSpeed and JumpPower.</li><li><code>Input.KeyDown/KeyUp</code> - Detects if a key is pressed/released. Can only be done on the client.</li><li><code>player:TakeDamage(amount)</code> - Damages the player.</li><li><code>player.Character.LookVector</code> - The direction they are facing.</li></ul></div><div><h3>Parts</h3><ul><li><code>World:FindFirstChild(name)</code> - Finds a part with the given name.</li><li><code>World:CreatePart()</code> - Creates a part.</li><li><code>part.Touched</code> - Detects if a player touches the part.</li><li><code>part.Color/Position/Size</code> - Self-explanatory.</li><li><code>part.Type = &quot;Kill&quot;</code> - Makes it a kill brick.</li><li><code>part.Anchored = false</code> - Gives it physics. Players can push it around.</li><li><code>part.Velocity / part:ApplyImpulse(v)</code> - Sets or pushes how an unanchored part moves.</li><li><code>part.Density/Friction/Elasticity</code> - How heavy, grippy and bouncy it is. Mass is size times density.</li><li><code>World:CreateWeld(a, b)</code> - Joins two parts so they move together.</li><li><code>World:Explode(position, radius)</code> - Blows things up, breaking welds and hurting players and NPCs.</li><li><code>World:Raycast(start, direction)</code> - Finds the first part along a line. Gives Position, Normal and Part.</li><li><code>World:GetHumanoidsNear(position, radius)</code> - Lists the players and NPCs nearby.</li><li><code>World.Gravity</code> - How hard everything falls. 115 is normal.</li></ul></div><div><h3>Models and NPCs</h3><ul><li><code>script.Parent</code> - The part or model the script is inside.</li><li><code>model:MoveTo(position)</code> - Moves a whole model.</li><li><code>humanoid:MoveTo(position)</code> - Makes an NPC walk there. MoveToFinished fires when it arrives.</li><li><code>humanoid:TakeDamage(amount)</code> - Hurts an NPC or player. Died fires at 0 health.</li><li><code>Head, Torso, Larm, Rarm, Lleg, Rleg</code> - Name the parts of a model with a Humanoid like this to make an NPC.</li></ul></div><div><h3>Timing</h3><ul><li><code>task.wait(seconds)</code> - Waits.</li><li><code>task.delay(seconds, fn)</code> - Runs fn after a while.</li><li><code>game:Announce(text, seconds)</code> - Dims the screen and shows big text in the middle for everyone. Good for a round starting.</li><li><code>game:Message(text, seconds)</code> - Shows a black bar with text along the top of everyone&#x27;s screen, out of the way. Leave out seconds to keep it up, and use game:Message(&quot;&quot;) to hide it. Good for countdowns.</li></ul></div><div><h3>Values and Storage</h3><ul><li><code>StringValue, IntValue, NumberValue, BoolValue, Vector3Value</code> - Right-click anything in the Explorer to add one. Put them in a part, a model or a script to make it easy to change settings.</li><li><code>script.Damage.Value</code> - Reads a value inside the script. Values in a part or model work the same way, like script.Parent.Health.Value.</li><li><code>value.Value = 40</code> - Changes a value. value.Changed fires with the new value.</li><li><code>game:GetService(&quot;Storage&quot;)</code> - Things in Storage are hidden from players until a script takes them out.</li><li><code>Storage.Maps.Arena:Clone()</code> - Copies something out of Storage into the world. Destroy the copy when you are done with it.</li><li><code>item.Parent = World</code> - Moves something out of Storage into the world.</li></ul></div><div><h3>Saving Data</h3><ul><li><code>DataStore:GetStore(name)</code> - Gets a store, such as &quot;Leaderstats&quot;.</li><li><code>store:Load(player)</code> - Waits for the player&#x27;s saved data and gives it back as a table.</li><li><code>store:Get(player, field)</code> - Gives one saved value.</li><li><code>store:Set(player, field, value)</code> - Saves a number, text or true/false.</li><li><code>store:Increment(player, field, amount)</code> - Adds to a number and gives the new total.</li><li><code>store:Remove(player, field)</code> - Deletes one value. store:Clear(player) deletes them all.</li><li><code>store:Save(player, { fields })</code> - Saves several fields at once, merging but not replacing the values.</li><li><code>store:Load(userId)</code> - Every store call also takes a user id, for players who are offline. Changes need a user who has played the game.</li></ul></div><div><h3>Teams and Tools</h3><ul><li><code>Teams:CreateTeam({ Name, Color })</code> - Creates a new team.</li><li><code>player:SetTeam(team)</code> - Adds the player to the team.</li><li><code>player:GiveTool(tool)</code> - Gives a tool to the player.</li><li><code>tool.Activated</code> - The player clicked with the tool. It also gives the point they aimed at.</li></ul></div></div><p>These are all from services, so you should start with <code>local Players = game:GetService(&quot;Players&quot;)</code>. You can also use <code>World</code>/<code>Teams</code>/<code>Tools</code>/<code>Remote</code>/<code>DataStore</code>.</p>
