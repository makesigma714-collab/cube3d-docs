# Should I use Server or Client?

<p>Short answer: server scripts can change the game, client scripts can’t.</p><p><b>Server scripts</b> run on our servers. Any changes that should actually happen in the game (moving parts, giving tools, damaging and adding points) should be in a server script. You will use these a lot.</p><p><b>Client scripts</b> run on the player’s computer. These are for when you want things to only show on that client’s screen. This could be opening a window or detecting key presses. If they want something to happen, they have to ask the server by using <code>Remote:FireServer</code>. The server has the final say. Never trust anything sent from a client script. There are exploiters.</p><p>New scripts start as server scripts. To make a client script, select it and set <b>Runs on</b> to <b>Each player</b> in Properties.</p>
