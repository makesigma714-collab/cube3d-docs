# API reference


Get a service with `game:GetService(name)`. Server scripts have `Players`, `World`, `Teams`, `Tools`,
`Remote`, `State`, `DataStore` and `Storage`. Client scripts have `Players`, `World`, `Teams`, `Remote`, `State`, `Tools`, `UI`, `Effects`, `Input` and `Build`. Storage is a local-development addition; see [Studio additions](/guide/studio-additions).



The member inventory below is generated from the current runtime source. Practical arguments and examples are covered in the guides.
